# ChatLookup

A client-side all-in-one chat utility mod!

## Features

**Message filtering** - an easy way to temporarily filter messages. Write anything in the search bar and only the matches will be shown on chat!

**Chat history saving** - the chat history is saved on your hard disk (can be turned off), so even after restarting the game you will still be able to see it!

**Match highlighting** - you can toggle highlighting the matches of your search. The color of the highlighter can be configured in the settings.

**Message copying** - `Ctrl+Left-click` any chat line to copy it to the clipboard. Also works while filtering - you copy exactly the message you see. `Ctrl+Shift+Left-click` a second message to copy the whole range between the two at once.

**Highlighted words** - keep a list of words you never want to miss. Each one gets its own color, its own bold/italic/underline/strikethrough styling, and can ping you with a sound when it shows up. Matching is plain text by default, or regex if you need it. Turn it on and edit the list under the Words tab in the settings.

**Command macros** - bind a key to a command or a chat message and fire it without opening chat. Set them up under the Macros tab in the settings: press the bind button, press the key you want, and Esc clears a binding.

**Inverted search** - flip the search around to hide every message that matches your phrase instead of showing it.

**Jump to surrounding** - while filtering, a small button appears in front of every match. Click it to drop the filter and land right on that message, so you can read what was said around it. The message then pulses for ten seconds so you can spot it instantly.

**Chat scrollbar** - a real, draggable scrollbar on the side of the chat instead of scrolling line by line.

**Math preview** - type an equation like `2+2` into the chat box and the answer pops up above it. Works mid-sentence too, and pressing `Tab` swaps the equation for the result. Supports `+`, `-`, `*`, `/` and brackets.

**And many more!** - message stacking, timestamps, mention detector, smooth chat animations...

Localized in English, Spanish, Russian and Polish.

## Configuration

The mod is highly configurable. You can easily turn off the functions you don't want to use.

In order to do so - simply click the settings icon using your mouse after opening the chat.
